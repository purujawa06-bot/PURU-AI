# manage_schedule output

> Create, list, update, remove, and enable/disable scheduled agent jobs. A job runs its prompt on its schedule (once, every N seconds, daily at a time, or cron). Use job_id from action=list/add for get/update/remove/enable/disable. Maximum duration and run limits are set via days/max_runs; both default to no limit.

## args

```json
{
  "action": "list"
}
```

## output

```
No scheduled jobs.
```
